# Power BI Dataviz World Champs: one repository, a folder per entry

This root holds no project of its own. Each folder is one contest round and a whole pbi-atelier project:

- `2027-round1-goodnight-inn/`: World Champs 2027, Round 1. Entered 16 Nov 2026. The current work.
- `2026-round3-movies/`, `2026-round2-the-boy-who-came-back/`, `2026-round1/`: Barcelona 2026. Closed.

**Before any work on an entry, read that folder's own `CLAUDE.md`** and treat the folder as the project root:
every path in its documents and scripts is relative to it, and its rules, skills and hooks live in its `.claude/`.
`README.md` here says what each folder holds, what is on this machine only, and where the folders came from.

A new round gets a new folder beside these (`<year>-round<n>-<name>/`), never files at this root.
