# Mission — wc-round-3

Win (or at minimum: proudly submit to) Round 3 of the Power BI Dataviz World
Champs BCN 26 with a report built end-to-end through this toolkit — the first
full stress test of the integrated pipeline. Deadline: **Aug 7, 2026,
11:59 p.m. PT**. Read `project/contest/contest-brief.md` before anything else.

**Round theme (binding): Using data responsibly.** Limitations, questioned
assumptions, honest uncertainty, no misleading conclusions — shown, not
lectured. This toolkit's contracts and do-not-fabricate discipline are the
entry's competitive edge; let the report demonstrate what it preaches.

## The 3-day battle plan (express lifecycle, gates still real)

**Day 1 — story and model (stages 0–4).**
- Manual first step (Bjorn, ~10 min): open `project/contest/World Champs
  BCN 26 - Round 3.pbix` in Desktop → File > Save As > PBIP →
  `project/pbip/`. Commit the converted source.
- /next through s0–s2 in one sitting: intake quotes the contest brief; s1
  finds the ONE question worth answering in 1M movies (the Key Takeaway
  candidate); s2 writes contracts for the 4–6 metrics that carry it.
  Time-box: propose, Bjorn confirms, move — G0/G1/G2 in hours, not days.
- s3/s4 light: the starter model is given — inventory it, blueprint only the
  deltas (a Date dim if absent, a _Measures table, profiling findings), build.
- Profile the data BEFORE the story locks: zero/na budgets, duplicate
  titles, adult flag, language/country skew. Do-not-fabricate list matters
  with judges who know this dataset.

**Day 2 — design (stage 5).**
- Three genuinely divergent directions as HTML comps (px-prototype),
  design-intelligence queried ("entertainment/media dashboard"), dials
  declared. Bjorn picks from rendered comps — the Round 2 lesson, now native.
- The Key Takeaway statement is a **contracted landing-page element** in the
  design handoff — it cannot fall off during the build.
- Imagery-studio candidates for the cover/signature moment (movie theme is
  a gift for this). Brand kit: bespoke mini-kit from the chosen direction
  (bk-brand-kit no-brand path, starter kits as accelerators).

**Day 3 — build, audit, submit (stages 6–7).**
- s6 verbatim-rect build against the comp; craft floor held; copy-polish
  sweep over every string (the Key Takeaway especially).
- Full validate-project + pbir_detect + **complete ax-audit** — Accessibility
  is 10 of 40 points; treat a11y findings as blockers, not polish.
- s7: rendered review in Desktop, business validation of the headline
  numbers against metric contracts, then submit via the Contests gallery
  ("Submit to contest") before the PT deadline — note PT vs CEST: 11:59 p.m.
  PT = 08:59 a.m. CEST **Aug 8**. Do not cut it that close.

## Standing waivers (recorded per lifecycle rules)

Contest context, single stakeholder, no client: UAT handoff and
nl-deliverables are out of scope; audience/decision mapping collapses to
"the judging panel deciding scores". Everything else — metric contracts,
design handoff quartet, gate evidence — stays binding: it is the stress test.
