## Compiled theme

`project/deliverables/theme.json`, generated by `project/tools/compile_theme.py`
from the kit. Validated 2026-11-06: `scripts/validate_json.py` clean;
**0 errors against Microsoft's report theme schema 2.159** (fetched from
microsoft/powerbi-desktop-samples, matching Desktop 2.159);
`scripts/check_contrast.py --theme` 8/8; UTF-8 without BOM.
Not emitted on purpose: `textClass.fontWeight` (a string in the schema with no
enumerated values, so unverifiable). Bold titles come from `title.bold`.
The visual header stays visible by default (show as table, focus mode).

## Consequences for later stages

- **Stage 5 contract:** the draft `creative-direction.draft.yaml` still
  describes every direction in navy, amber and Georgia/Segoe UI/Consolas.
  Whichever direction is chosen, its `visual_language` is restated from this
  kit; the structure of D1 (or D2's wall) is unaffected.
- **Headlines:** P1 "Do not disturb, since 2020."; P2 "Please make up the
  room." with a DAX subtitle bound to the plan builder. Wordplay nowhere else.
- **Sketch reports:** the three `project/pbip/*.Report` themes are written by
  `project/tools/sketch_reports.py`. Applying this theme to a sketch is a
  generator change (pbir-operator flow), not a hand edit of the JSON.
- **Icons:** `ic-icons` produces the set from brand-guide.md §7.
