# The organisers' package for Round 2 (World Champs BCN 26)

What the organisers handed out for Round 2: their starter report and model (pages Read Me, Sets, Minifigures,
Versions) and the LEGO data as CSV. Until 18 Nov 2026 this was the repository `world-champs-r2` in
`E:\World Champs R2`, described there as the Round 2 deliverable. It is not: every file equals the organisers'
download (`World Champs datasets.zip`, kept here) and the starter that was archived at the time. The entry itself
is the project one level up (`project/The Boy who came back.pbix`, `project/pbip/`).

| Folder or file | Contents |
| --- | --- |
| `World Champs BCN 26 - Round 2.pbip`, `.Report/`, `.SemanticModel/` | The starter project; opens in Power BI Desktop |
| `World Champs Round 2 Data/` | The contest CSVs, on this machine only (one file is 124 MB, over GitHub's limit) |
| `World Champs datasets.zip` | The whole package as downloaded, data included; this is what git keeps of the data |
| `MISSION-hp-world-champs.md` | An early copy of the mission brief; the project's own is `../project/MISSION-hp-world-champs.md` |
