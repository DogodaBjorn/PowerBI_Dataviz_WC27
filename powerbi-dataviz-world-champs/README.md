## How a folder works

Each entry folder is a whole project of its own, built on the
[pbi-atelier](https://github.com/DogodaBjorn/pbi-atelier) lifecycle: its own `CLAUDE.md`, skills, tools and
`.gitignore`. To work on an entry, open **its folder** as the working directory; every path in its documents and
scripts is relative to that folder. Start with the folder's `CLAUDE.md`.

A new round gets a new folder beside these: `<year>-round<n>-<name>/`.
